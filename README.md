An offline cover-art studio that turns your photos and a caption into GTA 6-style multi-panel poster art — Vice City grades, bold lettering, one-click PNG exports.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — pick a layout and a sunset grade, add your photos, drag to frame each panel, and export the cover as a PNG in 1080 × 1080, 1080 × 1350, 1920 × 1080 or 1080 × 1920.
