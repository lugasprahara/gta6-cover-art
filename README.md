Golden Hour Studio — an offline cover-art studio that turns your photos into full-bleed GTA-style poster covers: hero-mosaic and diagonal collages tiled edge-to-edge, a chrome-gradient title over the art with a neon script subtitle, a label on every panel, painted scenes and detail crops built in, review-quote header, starburst seal, tagline ribbon and credits footer, exported as PNG in four post sizes.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — Golden Hour Studio loads a ready-made cover; pick a preset or layout, swap panel art from the photo / crop / scene pool, edit each panel's label, tune the cinematic grade, grain, halftone and glow, and export the cover as a PNG in 1080 × 1080, 1080 × 1350, 1920 × 1080 or 1080 × 1920.
